# Preserved SEC fixtures

This directory contains only the useful SEC reference material extracted from
`Finance-Terminal-Salvage.zip`:

- five verified v3 issuer fixtures for Apple, Microsoft, Nvidia, Alphabet, and
  Berkshire Hathaway;
- 21 small provider-independent definitions under `metric-definitions/`.

The archive's old SEC client, parser, mappings, and application structure remain
reference-only and were not copied into the new package.
